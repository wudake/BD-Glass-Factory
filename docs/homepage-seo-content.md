# BDGLASS 首页内容规划（SEO + AIDA 模型）

> 主关键词：**China Glass Factory**
> 副关键词：China glass manufacturer, tempered glass factory China, insulating glass manufacturer, custom glass processing, glass supplier China
> 模型：**AIDA**（Attention → Interest → Desire → Action）
> 目标受众：海外门窗品牌采购商、建筑工程商、玻璃经销商

---

## 1. SEO 基础配置

### Meta Title
```
China Glass Factory - Tempered & Insulating Glass Manufacturer | BDGLASS
```
> 长度：68 字符（建议 ≤ 60，可接受）

### Meta Description
```
BDGLASS is a professional China glass factory specializing in tempered glass, insulating glass, laminated glass and custom glass processing. 3C certified, 15,000㎡ production base, exporting to 6+ countries. Get a quote today.
```
> 长度：155 字符（建议 ≤ 160）
> 触发词：professional, certified, 15,000㎡, 6+ countries, Get a quote

### URL
```
https://bdglassfactory.com/
```

### 目标关键词密度
- **China Glass Factory**：3-4 次（H1 + 正文 + Footer）
- **China glass manufacturer**：2-3 次
- **tempered glass**：2-3 次（含产品卡片）
- **insulating glass**：2-3 次
- **custom glass processing**：1-2 次

## 9. 页面加载性能对 SEO 的影响

- Hero 图片必须使用 `priority` + `preload`（LCP 优化）
- 产品卡片图片使用 `loading="lazy"`（非首屏延迟加载）
- Inter 字体 `font-display: swap` 防止 FOIT
- 首屏总 JS 体积控制 < 200KB（gzip）
- 目标 Lighthouse Performance ≥ 90
